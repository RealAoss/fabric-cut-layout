# Fabric Cut Layout

Compare two uniform layouts for rectangular fabric pieces. Measurements include seam allowances.

Open `index.html` in a modern browser. Edit the sample inputs to update the result, then print or download it. Processing stays in the tab.

## Example

Fabric width (cm) = 140, Fabric length (cm) = 200, Piece width (cm) = 30, Piece length (cm) = 40. The first result is 20.
